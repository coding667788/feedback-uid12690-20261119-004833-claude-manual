为离线 CI 实现构建产物来源核验器。声明绑定产物 SHA-256、源提交、构建者、签发时间、依赖摘要和模拟验签结果。按签发时间选择左闭右开授权，按仓库路径段匹配；历史撤销带发生时间与录入序号，查询的审计截点限制可见撤销，撤销可追溯到指定签发时间。声明对全部依赖取交集，同一依赖可选其任一完备证明；只有外部预置的可信源码可作叶子。

根产物需要两份可展开的证明，且二者所用非源码签发者集合互斥，两个分支可共用源码；证明内允许共享子图，但沿任一依赖路径重复同一产物即无效。先最小化两棵展开树合计声明出现次数，再按规范 DFS 的声明 ID 序列比较，依赖按摘要排序、两棵树排序归一。输出所选证明与可复核计数，失败区分无完备证明与无法组成独立对。单案上限 30 个产物、60 条声明、12 个签发者。测试覆盖局部最短组合无解而改选后成功、旁路打破循环、撤销追溯改变历史截点查询、共享依赖不重复伪造独立性。用穷举小图核对最优结果。

可信源码不计声明次数。同一产物在树的不同兄弟分支可选不同声明。对签发者集合较小却较长的备选证明也需正确判断。

在 Windows 原生 Python 3.12 上完成，仅用标准库和 CPU。所有输入自行合成，在本地测试目录离线运行。交付源码、README、可重放的 cases.json、自动化测试。统一提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v，README 写明输入结构、错误码、边界示例和实测结果。预期值须由独立判定或明确断言得出，测试不得从被测实现反推期望结果。
